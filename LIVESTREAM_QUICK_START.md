# How to Add Livestream to Your Events - Step by Step

---

## Step 1: Go to Events

In your admin panel, navigate to:
**Church Records → Events**

---

## Step 2: Create New Event

Click the **Add Event** button.

---

## Step 3: Fill in Event Details

Fill in these fields:

| Field          | What to Enter                                          |
| -------------- | ------------------------------------------------------ |
| **Title**      | Sunday Worship Service                                 |
| **Type**       | Select **Sermon**                                      |
| **Start Date** | When the livestream starts                             |
| **End Date**   | When the livestream ends                               |
| **Location**   | Main Sanctuary (or anywhere)                           |
| **Link**       | **Your streaming URL** (YouTube, Facebook Live, Vimeo) |

---

## Step 4: Save the Event

Click **Save**.

---

## Step 5: That's It! 🎉

**Before the event starts:**

- Status is "pending"
- Event won't show on live page yet

**When the event is happening:**

- Status automatically changes to "ongoing"
- Event appears on `/live` page with LIVE indicator
- Visitors can watch the stream

**After the event ends:**

- Status automatically changes to "completed"
- Event moves to the sermon archive
- Visitors can still watch the recording

---

## Example: Adding This Week's Sunday Service

Let's say today's Sunday service is at 9:00 AM to 11:00 AM:

1. Go to **Church Records → Events**
2. Click **Add Event**
3. Fill in:
   - **Title**: Sunday Worship Service - March 8, 2026
   - **Type**: Sermon
   - **Start Date**: 2026-03-08 09:00:00
   - **End Date**: 2026-03-08 11:00:00
   - **Link**: `https://www.youtube.com/watch?v=YourVideoID`
4. Click **Save**

Done! The livestream will appear on your website's `/live` page during service time.

---

## Need to Add a YouTube Link?

1. Go to your YouTube video or live stream
2. Click **Share**
3. Copy the link
4. Paste it in the **Link** field when creating the event

---

## Troubleshooting

| Problem            | Solution                                              |
| ------------------ | ----------------------------------------------------- |
| Stream not showing | Make sure Type = "Sermon"                             |
| Video won't play   | Use YouTube, Facebook, or Vimeo link                  |
| No LIVE indicator  | Check that current time is between start and end date |

---

## Summary

```
Create Event (Type: Sermon) → Add Link → Save
                ↓
    Status: pending (before service)
                ↓
    Status: ongoing (during service) → Shows on /live
                ↓
    Status: completed (after service) → Archive
```

It's that simple!
